# Verified facts (orchestrator-checked)

Reviewers apply these across all lessons. Each fact was verified against a source during the build. Rows 12 onward, and the corrections to rows 2, 6, 7 and 10, come from the 2026-10-18 check against the offline Ignition 8.3 manual; sources are page paths under `https://www.docs.inductiveautomation.com/docs/8.3/` (see docs/IGNITION_CLAIMS.md for the full per-claim results).

| # | Fact | Source |
|---|---|---|
| 1 | In Ignition 8.3, `system.tag.queryTagHistory` is **deprecated**; use `system.historian.queryRawPoints`. `system.tag.queryTagCalculations` → `system.historian.queryAggregatedPoints`. The old functions still run (backward compatibility). Teach the 8.3 API first, with an "In 8.1" callout for the old one. | https://www.docs.inductiveautomation.com/docs/8.3/getting-started/installing-and-upgrading/ignition-8-upgrade-guide/81to83-upgrade-guide |
| 2 | In 8.3, 192 is still the plain **Good** quality code (and `dataintegrity` 192 = Good in the historian tables), but several codes count as good (for example 201 Good_Initial). Use `isGood()` / `isBad()` / `qualityOf()` in expressions and `.quality.isGood()` in scripts rather than comparing to 192. | platform/tags/quality-codes-and-overlays; appendix/reference-pages/ignition-database-table-reference |
| 3 | The Redundancy "Failover Timeout" setting was removed in 8.1.37. (Not in the 8.3 manual; the 8.3 redundancy settings page has no such setting.) | https://inductiveautomation.com/downloads/releasenotes/8.1.37 |
| 4 | Sepasoft has **no separate Interlocking module**. Interlocks are features inside modules (e.g. Batch Procedure Permissive Start). Sepasoft MES 4.0 pairs with Ignition 8.3; 3.x with 8.1. Recipe & Changeover was renamed Settings & Changeover. | https://docs.sepasoft.com/articles/user-manual/permissive-start |
| 5 | Ignition Modbus driver defaults to one-based addressing (HR1 = 40001); zero-based is a device setting. | https://www.docs.inductiveautomation.com/docs/8.3/ignition-modules/opc-ua/opc-ua-drivers/modbus/modbus-address-mapping |
| 6 | Event Streams are 8.3 project resources (source → encoder → optional filter/transform → buffer → handlers). The offline 8.3 manual does not say whether they run on Ignition Edge; it does say the Kafka module is not available on Edge. | ignition-modules/event-streams |
| 7 | Ignition's built-in OPC UA server default endpoint port is 62541. The 8.3 Logix driver page lists Max Concurrent Requests and CIP Connection Size but no defaults; 2 and 500 are common values, not manual-verified. | appendix/reference-pages/gateway-port-reference; ignition-modules/opc-ua/opc-ua-drivers/allen-bradley-ethernet/connecting-to-logix |
| 8 | Logix: REAL → DINT conversion rounds (does not truncate). Major fault type 4 code 20 = array subscript out of range; type 6 = watchdog. PackML state numbers 1–17 as ISA-TR88.00.02. | Rockwell Major/Minor Fault codes; ISA-TR88.00.02 |
| 9 | Official Docker image `inductiveautomation/ignition`, data path `/usr/local/bin/ignition/data`, `GATEWAY_HTTPS_PORT` default 8043. | platform/advanced-deployments/docker-image; appendix/reference-pages/platform-environment-variables |
| 10 | In 8.3, `system.db.runNamedQuery` / `runSFNamedQuery` are **deprecated** → `system.db.execQuery` (SELECT), `system.db.execUpdate` (INSERT/UPDATE/DELETE); `execScalar` and `execUpdateAsync` also exist. The non-prepared `runQuery`, `runUpdateQuery`, `runScalarQuery` and `runSFUpdateQuery` are also deprecated; the prepared `runPrepQuery`, `runPrepUpdate`, `runScalarPrepQuery` and `runSFPrepUpdate` are **not** (the upgrade guide lists them as replacements). Old calls keep working. `clearNamedQueryCache` → `clearQueryCache(project, path)`. In Gateway scope pass `project=` by keyword; otherwise the Gateway falls back to an associated project or the Gateway scripting project. ("Pass `{}` not `None` for empty params" is not in the manual.) Teach 8.3 names first with an "In 8.1" callout. | getting-started/installing-and-upgrading/ignition-8-upgrade-guide/81to83-upgrade-guide; appendix/scripting-functions/system-db/system-db-execQuery |
| 11 | Logix ladder TON/TOF/RTO/CTU/CTD: the Preset (and Accum) fields take constants only. Change a preset at runtime with `MOV(tag, Timer.PRE)` or an ST assignment. CTU and CTD both set `.DN` when ACC >= PRE. | Rockwell Logix 5000 General Instructions reference |
| 12 | Ignition 8 replaced `system.tag.read`/`readAll` with `readBlocking` and `write`/`writeAll` with `writeAsync` (`writeBlocking` replaced `writeSynchronous`). `readBlocking`/`writeBlocking` time out after 45,000 ms by default. In 8.3 the Vision-only `system.gui`, `system.nav` and `system.util.invokeLater` move to `system.vision` (old names deprecated but working). There is no `system.printing`; it is `system.print`. | 79to81-upgrade-guide; appendix/scripting-functions/system-tag/system-tag-readBlocking; 81to83-upgrade-guide |
| 13 | The Gateway setting is called the **Gateway Scripting Project**. Tag event scripts and expression `runScript` can only call Project Library scripts in it. | platform/scripting/scripting-in-ignition/project-library |
| 14 | Perspective scripts all run on the Gateway, in the Perspective Session scope (or Gateway scope). `system.perspective.navigate`/`openPopup`/`print`/`download` work in Gateway scope only when `sessionId` and `pageId` are passed. `refreshBinding` is a component method (`self.refreshBinding(...)`), and `system.perspective.refresh()` is a real function that reloads the page. `system.perspective.sendMessage` cannot reach Session Events message handlers. | ignition-modules/perspective/scripting-in-perspective; appendix/scripting-functions/system-perspective/* |
| 15 | Project inheritance: runnable resources (Gateway event scripts, alarm pipelines, SFCs, transaction groups) run in **every leaf project** that inherits them, so keep them in a leaf or standalone project. | platform/projects/project-inheritance |
| 16 | Gateway event script types: Startup, Update, Shutdown, Timer, Tag Change, Message, Scheduled. Timer default is Fixed Delay. Message handlers default to the Shared thread pool. `system.util.sendMessage` scope is any of C, G, S, default all three. | platform/scripting/scripting-in-ignition/gateway-event-scripts; appendix/scripting-functions/system-util/system-util-sendMessage |
| 17 | Value Source types: Memory (default), OPC, Expression, Derived, Reference, Query. A memory tag's written value survives restart according to Value Persistence (None / Database / Configuration, inherited from the provider by default). Leased tag groups switch rate only when the tag is shown on an open window or view; the Tag Browser alone does not lease. | platform/tags/types-of-tags; platform/tags/tag-properties; platform/tags/tag-groups |
| 18 | UDTs predefine six parameters: InstanceName, ParentInstanceName, PathToParentFolder, TagName, PathToTag, RootInstanceName. Parameters have data types; numeric ones support math and formatting (`{BaseAddress+1\|000}`). | platform/tags/user-defined-types-udts/udt-parameters |
| 19 | Alarm modes include Above/Below/Between/Outside Setpoint(s), Out of Range, Equal/Not Equal, Bit State, When True/When False, Bad Quality, On Condition, Any Change. Default pipeline drop-out conditions: Acknowledged, Cleared, Shelved. Alarm journals store to a database, a remote Gateway's journal, or internally. | platform/tags/tag-properties/tag-alarm-properties; ignition-modules/alarm-notification/alarm-notification-pipelines; platform/alarming/alarm-journal |
| 20 | Expressions: `^` is power, `xor` is bitwise XOR. `tag(tagPath)` has no property argument. `switch(value, case1, case2, ..., result1, result2, ..., default)` lists all cases then all results; `case()` takes pairs. `now()` defaults to 1,000 ms; `now(0)` does not update. | platform/expression-language-and-syntax; appendix/expression-functions/* |
| 21 | 8.3 historian: `queryAggregatedPoints(paths, startTime, endTime, [aggregates], ...)` and `queryRawPoints` use `startTime`/`endTime`; quality aggregates are `PctGood`/`PctBad`. `system.tag.storeTagHistory` → `system.historian.storeDataPoints`. Providers are created at Services > Historians > Historians (Core Historian or SQL Historian). Core Historian (QuestDB) doesn't use store and forward; SQL Historian, transaction groups and alarm journals do. | appendix/scripting-functions/system-historian/*; ignition-modules/tag-historian/tag-history-providers |
| 22 | Named query parameter types: Value, QueryString (raw text, the only way to vary a table or column name), Database. Group named queries in a transaction with `system.db.beginNamedQueryTransaction` and pass `tx`. Store-and-forward cache limit in 8.3 is the Primary Store Maintenance Value (default 0 = no limit; 8.1 Max Records). | platform/sql-in-ignition/named-queries/named-query-parameters; appendix/scripting-functions/system-db/system-db-beginNamedQueryTransaction; platform/store-and-forward/configuring-store-and-forward |
| 23 | Tested databases: IBM DB2, MariaDB, MySQL, SQL Server, Oracle, PostgreSQL, Firebird, SQLite; DB2, Oracle and Firebird need the vendor driver installed. | platform/database-connections |
| 24 | 8.3 Gateway web UI sections: Home, Platform, Connections, Network, Services, Diagnostics (no Status/Config split). Devices: Connections > Devices > Connections. Modules: Platform > System > Modules. Alarm journals: Services > Alarming > Journals. | platform/gateway/web-interface; ignition-modules/opc-ua/opc-ua-drivers/programmable-device-simulator |
| 25 | 8.3 security: the Designer uses whichever **Designer Authentication Strategy** is set (Classic or Identity Provider); Perspective uses Identity Providers. Gateway Network: Require Two Way Auth on by default for new installs, connection policy ApprovedOnly by default, Allow Java Serialization off on new installs but on after an 8.1 upgrade. | platform/security/gateway-general-security-settings; platform/gateway-network |
| 26 | Leased licensing renews hourly; the timeout is 48 hours for leases generated up to July 19, 2026 and 72 hours from July 20, 2026. Trial mode runs two hours at a time and can be reset any number of times. Maker Edition: 10 Perspective sessions, 10,000 tags, non-commercial. Edge Panel: two Vision clients or Perspective sessions. | platform/licensing-and-activation/leased-licensing; platform/licensing-and-activation; other-editions/* |

Perspective's query binding is the **Query** binding (it runs a Named Query); "Named Query binding" is the Vision name. `system.dataset.toPyDataSet` is deprecated in 8.3 because datasets are already PyDatasets. | appendix/components/perspective-components/perspective-container-palette; .../bindings-in-perspective/query-bindings-in-perspective; platform/scripting/python-scripting/variables-datatypes-and-objects/datasets |
